The Oriented Return Construction:
A 26-Gate Heawood Circuit Reduction

A solver-independent constructive theorem

Abstract

A Lean-verified six-port law gives the finite relations T6 = I, M2 = I, and MTM = T−1. Exhaustive replay localizes all 36 errors of a measured Heawood near-circuit to two disjoint forbidden diagonals inside one nine-input return cell. The result below reduces the full 26-gate problem to an exact 10-gate construction of that cell.

Constructive Theorem

For Boolean variables p, q, r, a, b, d, c, e, f, define

S = p(a ∨ b ∨ c) ∨ q(a ∨ d ∨ e) ∨ r(b ∨ d ∨ f).

Theorem. If a 10-gate fan-in-two AND/OR/NOT circuit computes S, then a 26-gate circuit computes the edge function of the 14-vertex Heawood incidence graph.

Proof. Map the three terms of S to point stars 0, 1, and 6. Compute point stars 2, 3, 4, and 5 with three gates each, then join the five outputs with four OR gates. The seven stars partition the 21 graph edges, so their disjunction is exact, and the size is

10 + 4(3) + 4 = 26. ∎

Verification Status

The theorem is independent of any solver. The explicit 10-gate cell is the remaining finite target. A published assembler accepts a candidate only after the 512-row local table, all 16,384 full inputs, and Lean kernel checking agree.
